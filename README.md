# MangoBar Themes

Ready-to-use themes for [MangoBar](https://github.com/mangowm/mangobar), the status bar for MangoWM. Each theme includes a `config.jsonc` and a matching `style.css`.

### v1.0

Stable theme with a soft Catppuccin-inspired palette, rounded modules, and clear status colors.
