# 🥭 MangoBar Themes

Beautiful and ready-to-use themes for **[mangobar](https://github.com/mangowm/mangobar)** — the status bar for [mangobar](https://github.com/code-smith404/MangoBar-Themes).

This repository contains carefully crafted `config.jsonc` + `style.css` combinations to make your mangobar look modern and clean.
